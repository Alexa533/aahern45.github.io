Project — DigiClips Podcast Search

2

Podcast Search

In the last year, I have collaborated with the DigiClips founders in my senior capstone class at ASU, and have continued to work with them after graduation. When I started the project, there was no backend or frontend files in place for the podcast media type of the sponsor's website, and I have been creating, testing, and polishing my own compositions since then.
I have focused on developing a proper data scraping tool, which gathers selected metadata from multiple sources and displays it in a formatted page. Additionally, I created my own user interface for managing and displaying the scraped data during the development process.

Project — Arduino Game

3

Arduino Game

In this project, a classmate and I designed an interactive Arduino user interface where one can play a series of time-sensitive rounds.
Players have 3-5 seconds to press a button a certain number of times before the clock runs out, and is presented with a message of success or failure.

Project — Arduino Variety Board

4

Arduino Variety

After creating an Arduino project with another classmate, I wanted to try making one project on my own, where I could showcase my creation as my course's final project. On this board, there is a button which changes a rotation of friendly messages on an LCD screen when pressed, a potentiometer which changes the brightness of said LCD, another potentiometer that changes the brightneses of a singular LED, and lastly - an LED which turns on when sound is detected by an ultrasonic sensor (activating a buzzer as well).
